Short Course in Algorithmic Differentiation in Optimisation and Machine Learning
--------------------------------------------------------------------------------

This is the public repository of the course material. You will have access to the
course slides and python hands-on examples.

# Install
Python packages to install to get the examples running (prefer miniconda/anaconda)

```
conda create -n pyg_cpu -c pytorch pytorch_geometric pytorch cpuonly
conda activate pyg_cpu
conda install cma matplotlib numpy scipy
```
